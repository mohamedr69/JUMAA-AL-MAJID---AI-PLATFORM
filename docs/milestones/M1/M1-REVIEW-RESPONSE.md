## Future regression tests identified (not executed)

1. Submittal register vs map: the seven cases under `MS.status` (manual/map status conflict, missing revision with and without reference, deletion guard, post-edit check, idempotent re-check).
2. Compliance recheck: GET of a prepared statement with unchanged inputs writes nothing; with a changed BOQ hash flags only database/ai rows, withdraws approval once, writes one audit row per flagged row; legacy rows without `workflow` are upgraded once.
3. Battery calculation: a changed selection brand or battery unit recalculates the panel; a changed engineer setting recalculates only that panel.
3a. Automatic current fill, rejected no-load without evidence: part has a `rejected_no_load` rule, no included-in host, no settled equipment-table row and no acceptable datasheet reading/match -> the fill writes no rule and no equipment-table row (the unsupported zero-current assumption is not recreated; the part stays a lower bound).
3b. Automatic current fill, rejected no-load with datasheet evidence: same part but `_read_from_datasheets` returns a reading and a match -> the fill writes a `part.current` version with the read standby/alarm figures, `auto=true` and the datasheet cited, and upserts an unconfirmed equipment-table device row (permitted evidenced write; the rejection does not block it).
3c. Automatic current fill, settled equipment-table value: the part has a settled `EquipmentCurrent` row -> the fill copies it into a `part.current` version through `rule_data` before any rejection or datasheet logic (line 347) and reads no datasheet; this holds even when a `rejected_no_load` rule exists.
3d. Automatic current fill, included-in-module host: `included_in_module` names a host -> no datasheet is read and a `no_load` rule with `included_in=host` is written. Current behaviour: this happens even when the part carries `rejected_no_load` (gap G-04). Target expectation to decide in M4: a rejection stands until an engineer reviews the host relationship; the test must be written against whichever semantics M4 confirms, and must not silently generalise the rejection rule to hosts.
4. Floor schedule: a manual material choice on an ambiguous row after a workbook change (documents the current loss; target: preserved).
5. Project: PUT with `source_folder_path` or `status` in the body leaves both unchanged.
6. Date references: extraction of the 18 Golden documents (including 687) yields no date-shaped reference at top level or in any record.
7. Generic references: after repair, none of the 86 embedded-exact documents carries `ICC-DLRC-SPM-SD-MEP` as a record reference, and the 7 prefixed full references (771-776, 784) are unchanged.
