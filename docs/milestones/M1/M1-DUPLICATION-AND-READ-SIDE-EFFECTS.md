## Business-state inference paths (must not become authorities)

- Frontend: `ProjectHomePage.bucket@399` maps status strings to approved/review/rejected; `ProjectLogsPage` colours codes. Both read only; but Home's StatCards are a client-side business summary.
- Folder words: `document_control.is_shop_drawing@436` (enquiry/tender/IFC folders), `submittal_replies.on_file@43` / `for_revision@65` (received/approved folders and file-name letters), `submittal_scanner.APPROVAL_FOLDER_RE@68`, `document_classification._RECEIVED_RE` (hint component only).
- File presence: `required_drawings.status@90` treats files in a named folder as 'received'.
- Register overwrite: `submittal_reader.sync_register@666` assigns revision and submittal status from the AI map without a manual/ai_check guard (see MS.status and G-01); an engineer value that differs from the map does not survive the next check.
- Reply heuristics: `document_control.combine@1247` folds a reply by reference/listed sheet; `shop_drawings._ai_review@579` iterates raw reply records without a full target-domain/author gate (prior audit, re-verified).
- Sample receipt: a signed transmittal is a receipt, never approval (`content_evidence` receipt kind; `SMP.status` stays UR).

## Read-time duplicates of identity logic

- Reference grammar and cover parsing live in `document_control`; part identity in `boq_provenance`/`part_catalog`; submittal identity in `submittal_identity.submittal_key@49`; drawing identity in `document_control.combine.drawing_key` (floor first) and `shop_drawings._reference_shape@493`.
- Revision numbering: six helpers (see table). Systems: seven rule sets.

## Target invariant vs current behaviour (R1)

Engineer-status protection on material submittals is a **target invariant** (roadmap: preserve engineer overrides and their history) and a **current implementation gap (G-01)**. History alone is not protection: `project_submittal_status_history` records the replacement, it does not prevent it. Regression cases to add when M4 changes the writer are listed in the MS.status row of the matrix (seven cases: differing manual/map statuses, missing revisions with and without reference, deletion guard, post-edit checks, idempotent re-checks). None has been executed.
