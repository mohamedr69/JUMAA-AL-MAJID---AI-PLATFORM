## Boundary kept

Assigning an effective approval, a revision to a decision, a system to a register row, or a submission to a reply beyond listed-sheet overlap is domain processing (M4) and was not changed. Folder names are used for nothing new; where they were already used (revision), the use is now labelled. No classifier, role rewrite, calculation, current-fill policy, effective-system rule, approval rule or reconciliation behaviour was touched. G-04 was not "fixed" by suppressing automatic current writes.
